# Rancangan akhir (WBS 1.2)

Dokumen DOCX pada root dan PDF dalam docs/ disalin utuh dari proyek sumber.
SQL final memakai 13 tabel independen, dengan primary key id pada setiap tabel.
Tidak ada foreign key atau JOIN. Kata "relasi" pada WBS tidak sesuai dengan
artefak final; repositori ini mempertahankan rancangan yang benar-benar tersedia.
Dokumen asli memuat rencana/fitur tahap selanjutnya, termasuk admin dan form.
Keberadaannya pada dokumen bukan bukti implementasi tahap tersebut di repo ini.
